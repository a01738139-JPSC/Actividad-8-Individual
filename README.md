# Actividad 8 (Regresión NO Lineal)

Análisis de regresión no lineal con la base de existencias de CLV (Existencias_04_09_2026).

## Archivos
- `Act8_Regresion_No_Lineal.ipynb`: preprocesamiento (nulos, outliers, transformaciones), modelos no lineales y tabla de coeficientes.
- `Reporte_Actividad8_Regresion_No_Lineal.pdf`: reporte comparativo.
- `Tabla_coeficientes.csv`: R² y R de cada correlación y modelo.
- `Existencias_limpias.csv`: datos después del preprocesamiento.
- Bases de datos: `Existencias_04_09_2026.csv`, `Ventas_CLV_2022_2026.csv`, `Datos_CLV_2026_Tec_v2.xlsx`, `Datos_Complementarios_CLV.xlsx`.

## Modelos
- Función cuadrática: y = a·x² + b·x + c
- Función exponencial: y = a·e^(-b·x) + c
